# 05 · 环境搭建与迁移指南

## 1. 启动基础设施

```bash
# 在项目根目录
docker compose up -d
docker compose ps   # 确认 postgres / redis 均 healthy
```

| 服务 | 端口 | 账号 | 说明 |
| --- | --- | --- | --- |
| PostgreSQL 16 | 5432 | cms / cms_secret | 数据库 cms |
| Redis 7 | 6379 | — | 缓存 / 锁 / Celery broker |

> RabbitMQ 可省略：本项目 Celery 直接用 Redis 作为 broker（无需额外起 RabbitMQ）。

## 2. 初始化 FastAPI 后端

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

`requirements.txt`：

```text
fastapi>=0.110
uvicorn[standard]>=0.29
sqlalchemy[asyncio]>=2.0
asyncpg>=0.29
alembic>=1.13
pydantic>=2.6
pydantic-settings>=2.2
python-jose[cryptography]>=3.3
passlib[bcrypt]>=1.7
python-multipart>=0.0.9
celery[redis]>=5.3
redis>=5.0
pytest>=8.0
pytest-asyncio>=0.23
httpx>=0.27
```

> 建议 Python 3.11/3.12。若用 3.13，`passlib` 与新版 `bcrypt` 有兼容告警，可将 `passlib` 替换为 `pwdlib` 或直接使用 `bcrypt`。

## 3. 环境变量

新建 `backend/.env`：

```env
DATABASE_URL=postgresql+asyncpg://cms:cms_secret@localhost:5432/cms
REDIS_URL=redis://localhost:6379/0
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/1
SECRET_KEY=change-me
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=15
REFRESH_TOKEN_EXPIRE_DAYS=7
```

## 4. 数据库迁移（Alembic）

```bash
cd backend
alembic init alembic
# 在 alembic/env.py 中配置 async engine，导入 app.models
alembic revision --autogenerate -m "init"
alembic upgrade head
```

## 5. 启动

```bash
# 终端 1：API（端口 8000，前端 proxy 已对齐）
cd backend && source .venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 终端 2：Celery worker（异步任务）
celery -A app.tasks.celery_app worker --loglevel=info

# 终端 3：Celery beat（定时调度）
celery -A app.tasks.celery_app beat --loglevel=info
```

访问 `http://localhost:8000/docs` 查看自动生成的 OpenAPI 文档。

## 6. 前后端联调

```bash
# 终端 4：前端（后端未就绪时默认走 MSW mock）
cd frontend && pnpm install && pnpm dev
```

后端就绪后，将 `frontend/.env` 中 `VITE_USE_MOCK` 改为 `false`，前端请求经 `/api` 代理到 `localhost:8000`。

## 7. 常见问题

- **端口冲突**：改 `docker-compose.yml` 的 `ports` 与 `.env` 中的 URL。
- **asyncpg 连接失败**：确认 postgres healthy，`DATABASE_URL` 账号密码一致。
- **Alembic autogenerate 为空**：确认 `alembic/env.py` 导入了 `app.models` 的 `Base.metadata`。
- **Celery 任务不执行**：确认 worker 已启动，broker URL 一致，任务被正确 import。
