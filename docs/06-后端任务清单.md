# 06 · 后端任务清单（分阶段验收）

> 依据：前端已实现功能 + `docs/03-api-契约.md`。每个阶段完成后，用「前端联调」作为验收手段——前端页面、接口字段均已就绪，后端实现即插即用。

---

## 阶段 1：地基 + 认证登录

**目标**：项目能跑起来，能登录、能续期、未登录被拦截。

### 任务
- [ ] 初始化后端项目结构（按 `docs/05` 的目录建议）
- [ ] 打通数据库连接与数据模型迁移
- [ ] 统一响应包装（`{ code, message, data }`）与全局异常处理
- [ ] 参数校验（入参 DTO 校验，非法参数返回 400）
- [ ] 登录接口：校验用户名密码，返回令牌 + 用户信息 + 租户 + 权限码
- [ ] 令牌续期接口（支持令牌轮换）
- [ ] 当前用户信息接口
- [ ] 登出接口（吊销令牌）
- [ ] 认证守卫：未登录访问受保护接口返回 401

### 对应接口
| 方法 | 路径 |
| --- | --- |
| POST | `/auth/login` |
| POST | `/auth/refresh` |
| GET | `/auth/profile` |
| POST | `/auth/logout` |

### 验收标准
- [ ] 前端登录页用 `admin / admin123` 能登录并跳转工作台
- [ ] 令牌过期后前端能无感刷新，不被踢出
- [ ] 不登录直接访问接口返回 401，前端自动跳登录页

---

## 阶段 2：多租户 + 租户管理

**目标**：数据按租户隔离，租户可增删改查。

### 任务
- [ ] 请求上下文提取租户标识（登录后前端会带租户头）
- [ ] 所有业务数据读写强制带上租户维度（数据层统一注入，杜绝越权）
- [ ] 租户分页列表（支持关键词搜索）
- [ ] 租户全量列表（登录页/顶栏切换用）
- [ ] 租户新增 / 编辑 / 删除

### 对应接口
| 方法 | 路径 |
| --- | --- |
| GET | `/tenants` |
| GET | `/tenants/all` |
| POST | `/tenants` |
| PATCH | `/tenants/:id` |
| DELETE | `/tenants/:id` |

### 验收标准
- [ ] 租户管理页能正常分页、搜索、增删改
- [ ] 顶栏切换租户后，各页面数据随之切换（数据隔离生效）
- [ ] 用租户 A 的令牌访问租户 B 的数据，返回 403 或查不到

---

## 阶段 3：RBAC（成员 / 角色 / 权限）

**目标**：用户-角色-权限模型跑通，接口级权限生效。

### 任务
- [ ] 权限码清单接口（返回分组后的权限码，供勾选）
- [ ] 角色列表 / 新增 / 编辑（含权限码配置）/ 删除
- [ ] 成员分页列表（支持关键词搜索）
- [ ] 成员新增 / 编辑（含角色分配）/ 删除
- [ ] 权限守卫：接口标注所需权限码，无权限返回 403
- [ ] 登录时返回当前用户的权限码集合（前端据此控制按钮显隐）

### 对应接口
| 方法 | 路径 |
| --- | --- |
| GET | `/permissions` |
| GET | `/roles` |
| POST | `/roles` |
| PATCH | `/roles/:id` |
| DELETE | `/roles/:id` |
| GET | `/users` |
| POST | `/users` |
| PATCH | `/users/:id` |
| DELETE | `/users/:id` |

### 验收标准
- [ ] 成员管理页、角色权限页能正常增删改，角色能勾选权限
- [ ] 不同角色登录后，左侧菜单和页面按钮按权限显隐
- [ ] 无权限接口返回 403

## 阶段 4：内容主线（栏目 / 内容 / 多语言）

**目标**：核心业务跑通——建栏目、写内容、配多语言。

### 任务
- [ ] 栏目树接口（返回树形结构）
- [ ] 栏目新增 / 编辑 / 删除
- [ ] 栏目排序接口（拖拽排序）
- [ ] 内容分页列表（支持关键词 / 状态 / 栏目筛选）
- [ ] 内容详情（含多语言翻译）
- [ ] 内容新增 / 编辑（含多语言翻译的写入）
- [ ] 内容删除（建议软删除）

### 对应接口
| 方法 | 路径 |
| --- | --- |
| GET | `/categories/tree` |
| POST | `/categories` |
| PATCH | `/categories/:id` |
| DELETE | `/categories/:id` |
| PATCH | `/categories/reorder` |
| GET | `/contents` |
| GET | `/contents/:id` |
| POST | `/contents` |
| PATCH | `/contents/:id` |
| DELETE | `/contents/:id` |

### 验收标准
- [ ] 栏目管理页能建树、增删、加子栏目
- [ ] 内容管理页能筛选、分页，列表正确显示标题/栏目/状态/作者/版本
- [ ] 内容编辑页能新增/保存，多语言标签页能分别保存标题/正文/摘要/SEO
- [ ] 列表页的「新建内容」「编辑」能正常跳转与回显

## 阶段 5：版本管理

**目标**：每次保存留快照，能对比、能回滚。

### 任务
- [ ] 保存内容时自动生成版本快照（记录标题/摘要/正文/操作人/备注）
- [ ] 版本历史接口（按内容返回版本列表）
- [ ] 回滚接口（读快照写回正文，版本号递增）

### 对应接口
| 方法 | 路径 |
| --- | --- |
| GET | `/contents/:id/versions` |
| POST | `/contents/:id/versions/:versionId/rollback` |

### 验收标准
- [ ] 内容编辑页点「版本历史」能列出历史版本
- [ ] 版本弹窗能展示历史与当前版本的差异
- [ ] 点「回滚到此版本」后正文回退且版本号 +1

---

## 阶段 6：审核流 + 发布 + 定时发布

**目标**：内容走完「草稿 → 审核 → 发布」全流程，支持定时发布。

### 任务
- [ ] 提交审核接口（草稿 → 待审核）
- [ ] 审核列表接口（按状态筛选）
- [ ] 审核通过 / 驳回接口（写审核意见，驳回回到草稿）
- [ ] 立即发布接口（已审核 → 已发布）
- [ ] 下线接口（已发布 → 已下线）
- [ ] 定时发布接口（设置预约时间）
- [ ] 定时发布触发（到点自动发布，多实例下不重复触发）

### 对应接口
| 方法 | 路径 |
| --- | --- |
| POST | `/contents/:id/submit` |
| GET | `/reviews` |
| POST | `/reviews/:id/approve` |
| POST | `/reviews/:id/reject` |
| POST | `/contents/:id/publish` |
| POST | `/contents/:id/archive` |
| POST | `/contents/:id/schedule` |

### 验收标准
- [ ] 内容列表页的操作菜单按状态正确显隐（草稿可提交、已审核可发布等）
- [ ] 审核中心能看到待审内容，通过/驳回后状态正确流转
- [ ] 定时发布到点后状态自动变为已发布

- [ ] 工作台统计接口（内容/发布/待审/成员/媒体数量、趋势、栏目分布、最近动态）
- [ ] 热点内容缓存（可选）
- [ ] 单元测试 / 集成测试覆盖核心逻辑
- [ ] 结构化日志 + 请求追踪标识

### 验收标准

- [ ] 标签管理能增删改，内容编辑页能选标签
- [ ] 操作日志页能看到各模块操作记录

- [ ] 核心模块有测试覆盖，接口日志带请求标识

## 阶段 8：异步任务与定时调度

**目标**：把耗时操作与周期任务从主链路剥离，掌握队列与调度能力。详细设计见 `docs/07-异步任务与定时调度设计.md`。

### 任务
- [ ] 搭建任务队列与调度基础设施（队列划分、worker 进程）
- [ ] 通知任务：审核通过/驳回/发布后异步通知作者
- [ ] 媒体处理任务：上传后异步生成缩略图、压缩、提取元数据
- [ ] 发布后处理任务：发布后异步预热缓存、生成快照
- [ ] 批量操作任务：批量发布/导入，进度写入缓存供前端轮询
- [ ] 报表导出任务：异步生成 CSV/Excel，完成后通知下载
- [ ] 定时调度：每日统计快照、待审超时提醒、定时发布兜底扫描、过期数据清理、热门缓存预热、健康检查

### 验收标准
- [ ] 审核通过后作者异步收到通知（不阻塞审核响应）
- [ ] 上传图片后后台异步生成缩略图
- [ ] 批量操作能看到进度反馈
- [ ] 定时任务按 cron 周期执行，日志可查
- [ ] 同一任务不重复执行（幂等）
